# WindowsProtect MeshCentral server

This directory defines the remote-support server used by WindowsProtect.

## Why this is separate from DeviceHost

DeviceHost remains the security-health dashboard. MeshCentral handles interactive remote control through its own authenticated web console. DeviceHost does not expose a remote shell.

## Version

Pinned to MeshCentral 1.2.6. Do not switch to `latest` without testing the update first.

## Server requirements

- Small always-on Linux VPS
- Docker + Docker Compose
- Public TCP ports 80 and 443
- A DNS hostname pointing to the VPS
- Outbound internet access

For a small family fleet, the local MeshCentral database is sufficient. The `data`, `files`, and `backups` directories are persistent.

## Install

1. Point a hostname such as `remote.example.com` to the VPS public IP.
2. Copy this `meshcentral` directory to the VPS.
3. Run:
   ```
   sudo bash setup.sh
   ```
4. Open the HTTPS URL printed by the script.
5. Create the first administrator account.
6. Enable and verify two-factor authentication.
7. Create one device group named `Family PCs`.

## Security defaults

- HTTPS on 443 with Let's Encrypt.
- HTTP only redirects to HTTPS.
- No public account sign-up after the first administrator.
- 2FA required by password policy.
- Strong 14+ character account passwords.
- Saved device credentials disabled.
- Guest device sharing enabled.
- Agent self guest-sharing default expiry: 120 minutes.
- Daily server backups retained for 14 days.
- MeshCentral console/config/upgrade controls hidden from routine UI.

## Temporary technician access

Use MeshCentral guest/device sharing. Set the share to expire after 2 hours or revoke it earlier from the MeshCentral device sharing screen. Do not create a permanent technician account for one-off help.

## Windows agent

The final WindowsProtect package must use the agent generated by THIS MeshCentral server for the `Family PCs` group. MeshCentral agents are tied to the server and device group, so the final Windows package is produced only after this server/group exists.

On current Windows builds, the supported command-line install is the downloaded MeshCentral agent with `-fullinstall`. This avoids the Windows 11 24H2 GUI-install issue reported in older agent flows.
